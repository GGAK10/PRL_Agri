About

AOI-based time-series vegetation, soil and yield mapping from Sentinel-2 (10 m, open data).
Indices: NDVI, SAVI, BSI, NDSI*
Yield: Y = (6 × NDVIpeak − 1) × Fvariety × Firrigation × calibration, using the 90th-percentile NDVI of the selected season.
Dates: if too few clear scenes exist, the server widens the date range / cloud limit automatically and tells you what it used.
Features: draw AOI, run analysis, GeoTIFF download, place search, 3D view, live stats and trend chart.
*NDSI here is (SWIR − NIR)/(SWIR + NIR), a moisture index, not true snow NDSI.
